# 可选适配器：本地 markdown 排版

> **默认不生效。** 只有当项目在 `plan.md` 里显式写上 `target: local-md` 时，本约定才参与 Plan 与定稿自查。
> 不绑定它时，规范型文档只跑通用检查（结构完整、引用无悬挂、命名合规），不套模板。
>
> 来历：v1 把这份规范硬编码进主链路，导致不写策划案的项目也被套上"章末小结""中文数字章节"，属反向伤害。v2 降级为可选。

## 一、绑定方式

在 `.spec-pact/plan.md` 头部声明：

```
> target: local-md
```

未声明 = 不生效。**不要默认给它套模板。**

## 二、头部元信息（引用块）

正文之前用 blockquote 写固定字段，**无内容则留空，不删字段**：

```markdown
> **适用版本**：
> **文档定位**：
> **文档作者**：
> **二校**：
> **外部团队依赖**：
> **最后更新时间**：2026-10-28
```

## 三、标题与编号

- 一级（大章）：`#` + 中文数字 + 顿号，`# 零、阅读指引`、`# 一、xxx`
- 二级：`## 1.1`、`## 1.2`（父章号 + 序号）
- 三级：`### 1.1.1`
- 最多到三级；再细分用加粗小标题或 checklist，不再加数字层级

## 四、骨架

```markdown
# 零、阅读指引
（一段话总括：写了什么、给谁看、怎么读）

## 外部文档引用
（全文外部引用的总清单）

# 一、<主题>
## 1.1 <小节>
## 1.2 小结
- 本章外部引用：《xxx》
- 注意事项：……

# 二、<补充事项 · 风险 · Plan B>
## 2.1 未做完 / 待确认
## 2.2 风险评估
## 2.3 Plan B
```

- 每个大章的**最后一个二级标题必须是「小结」**，含"本章外部引用"+"注意事项"两块
- **末章**固定收口：未做完 / 待确认 · 风险评估 · Plan B

## 五、来源标注

- 默认**全部放章末小结**统一列，不在段落行内标
- 只在关键数据、易引争议的结论处，就近标一次来源

## 六、书写约定

- 大章用中文数字，章内用阿拉伯数字；**不使用 ①②③ 圈码**
- 待办 / 清单优先 `- [ ]`
- 表"提升 / 下降"用**文字**，不用 ↑↓；`→` 只用于因果与流程连接

## 七、与其他协议层的关系

| 层 | 是否强制 |
|---|---|
| 三向一致性、决策留痕、路径命名 | ✅ 强制（协议内核，与本适配器无关） |
| 本章的排版约定 | ⚠️ 仅在 `target: local-md` 时生效 |
